# جمعيتي | Jamaity OS

منصة SaaS سعودية لإدارة الجمعيات الأهلية، مبنية حول **الثقة، سهولة الاستخدام، والسرعة**.

## ما تم تأسيسه
- واجهة عربية RTL بروح سعودية حديثة.
- تسجيل دخول وإنشاء حساب عبر Supabase Auth.
- استعادة كلمة المرور عبر رابط آمن يُرسل إلى البريد الإلكتروني.
- Dashboard أولي للجمعية.
- صفحة عامة لكل جمعية: `/charity/<CHARITY_ID>` لنشر آخر التطورات والمبادرات.
- نموذج بيانات متعدد المستأجرين (Multi-tenant) في PostgreSQL.
- RLS لعزل بيانات الجمعيات على مستوى قاعدة البيانات.
- صلاحيات قابلة للتوسع: أدوار + صلاحيات دقيقة + Overrides.
- كيانات المستفيدين والحالات والدعم والمتبرعين والتبرعات وسجل التدقيق.
- فهارس أساسية للبحث والتصفح السريع.

## الرؤية
جمعيتي ليست برنامج محاسبة فقط؛ بل نظام تشغيل للجمعية: المستفيد، الحالة، الدعم، المتبرع، الفريق، الحوكمة، والتقارير في رحلة واحدة.

## الأمان
لا يتم وضع مفاتيح Supabase السرية في الواجهة. يستخدم التطبيق Publishable Key فقط، بينما تعتمد الحماية الحقيقية على PostgreSQL RLS والصلاحيات من الخادم/قاعدة البيانات. البيانات الحساسة يجب أن تبقى في Storage خاص مع روابط موقعة عند إضافة المستندات.

## المرجعية السعودية
تصميم المنتج يراعي أنظمة ولوائح القطاع غير الربحي المنشورة من المركز الوطني لتنمية القطاع غير الربحي، مع ضرورة مراجعة المستشار النظامي قبل وصف المنتج بأنه "متوافق قانونياً" بشكل نهائي.

## التشغيل
انسخ `.env.example` إلى `.env.local` وضع:

```env
VITE_SUPABASE_URL=...
VITE_SUPABASE_PUBLISHABLE_KEY=...
```

ثم:

```bash
npm install
npm run build
npm run dev
```

> أضف عناوين النشر المسموحة ومسار `/reset-password` إلى إعدادات Redirect URLs في Supabase Auth قبل الإطلاق.
